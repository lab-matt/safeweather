# Project layout

This is a single-file web app. Keep `index.html` at the repository top level so GitHub Pages can serve it. Keep `AGENTS.md`, `spec.md`, and `prompts.md` at the top level too.

Save new files in the folder that matches their purpose:

- `00_planning/` — planning notes and sketches.
- `01_data/` — data files.
- `02_validation/` — hand calculations and test cases.
- `03_output/` — screenshots and exported results.

Add a short `README.md` in each numbered folder describing its contents. Do not place the app's `index.html` in a numbered folder.

## Request log instruction

After each request, add an entry to `prompts.md` describing what was asked, what changed, and whether it worked.
